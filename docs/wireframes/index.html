How to get your key (2 minutes)
  1. Go to console.anthropic.com and sign up or log in.
  2. Settings, Billing: add a payment method and a small credit.
  3. Settings, API Keys: click Create Key, name it "ScanPro".
  4. Copy the key now (starts with sk-ant-). It is shown once.
  5. Paste it below, then click Save and test.
